# 扫雷

一个使用 Vite、React、TypeScript 和本地 Node 服务实现的扫雷游戏。排行榜与游戏设置会保存到项目目录中的本地 JSON 文件。

## 功能

- 三档难度：简单、正常、困难。
- 技能卡「范围探测」：探明 3 x 3 区域内的地雷，每局可用次数可自定义。
- 首次有效左键后布雷，保证首点安全。
- 左键翻格、右键红色旗帜标记、空白区域自动展开。
- 胜负判定、计时和重新开始。
- 通关公告、加入排行榜和本地排行榜查询。
- 排行榜按用时从短到长排序，每页最多显示 10 条记录。
- 难度与技能卡次数保存在服务端文件，下次打开自动沿用上次选择。

## 环境要求

- Node.js 18 或更高版本
- npm

## 安装

在项目根目录执行：

```bash
npm install
```

## 开发模式

执行：

```bash
npm run dev
```

该命令会同时启动：

- Vite 开发服务器：通常为 `http://127.0.0.1:5173/`
- 本地数据服务：`http://127.0.0.1:3001/`

在浏览器打开终端显示的 Vite 地址即可进入游戏。接口会自动代理到本地服务，因此开发时不需要额外启动第二个终端。

使用 `Ctrl+C` 可以同时停止两个服务。

## 生产运行

先构建前端：

```bash
npm run build
```

再启动本地服务：

```bash
npm run start
```

浏览器访问：

```text
http://127.0.0.1:3001/
```

`npm run start` 会提供构建后的页面、排行榜接口与设置接口。

> 注意：请使用 `npm run dev` 或 `npm run start`。如果只用 `npm run preview`，因为没有本地服务，排行榜与设置都无法读写，页面会显示提示并回退到默认设置。

## 游戏操作

- **左键**：翻开格子。
- **右键**：为未翻开的格子添加或取消红色旗帜。
- **设置**：打开设置面板，调整难度与技能卡次数。
- **重新开始**：重置当前棋盘、计时与技能卡次数。
- **查看排行榜**：查看本地通关记录；可使用上一页、下一页浏览更多记录。
- **技能卡**：位于棋盘下方，点击后在棋盘上再点一次即可发动。

## 技能卡：范围探测

- 先点击技能卡，卡片进入**待命**状态，再点击棋盘上的任意格子发动。
- 发动后探明以该格为中心的 **3 x 3** 范围内所有地雷，并以琥珀色标记显示。
- 待命时再点一次技能卡可以取消，取消不消耗次数。
- 待命时右键仍然正常插旗，技能保持待命。
- 技能只做探测：**不会翻开**点击的格子，也不影响踩雷判定，探明的雷仍然需要自己插旗。
- 探明的雷如果被左键点击，依然会判负。
- 首次翻开格子之前（`ready` 状态）以及本局结束后，技能卡不可使用。
- 次数用完后技能卡变灰，需要重新开始或调整设置才能再次使用。
- 被探明的标记会一直保留到本局结束。

## 设置

点击顶部的「设置」按钮可以调整：

| 设置项 | 可选值 |
| --- | --- |
| 难度 | 简单 9 x 9 / 10 雷、正常 10 x 10 / 20 雷、困难 12 x 12 / 30 雷 |
| 技能卡每局可用次数 | 0 – 5，与难度无关；0 表示本局不使用技能卡 |

修改任意一项都会**立即重新开始本局**，并把设置保存到 `data/settings.json`，下次打开页面会沿用上次的选择。

## 难度

| 难度 | 棋盘 | 地雷数 |
| --- | --- | --- |
| 简单 | 9 x 9 | 10 |
| 正常 | 10 x 10 | 20 |
| 困难 | 12 x 12 | 30 |

## 数据存储

两个文件都位于项目根目录的 `data/`：

### `data/leaderboard.json`

每次在通关公告中点击「加入排行榜」时，服务会保存：

- 本局用时
- 所选难度
- 使用 UTC+8 格式记录的完成时间

记录按总用时从短到长排序。清空该文件内容即可删除排行榜记录。

### `data/settings.json`

保存当前的难度与技能卡次数，格式示例：

```json
{
  "difficulty": "easy",
  "skillUsesPerGame": 1
}
```

删除该文件后，服务会回退到默认值（简单难度、1 次技能卡）。

> 排行榜**不区分是否使用技能**，用时排名会同时包含使用技能的成绩。

## 项目结构

```text
src/
  components/               状态栏、棋盘、格子、技能卡和各类弹窗
  game/                     扫雷规则、难度、技能、设置与排行榜 API 客户端
  App.tsx                   游戏状态与交互连接
  styles.css                全局样式
server.mjs                  排行榜 / 设置 API 与生产静态文件服务
scripts/dev.mjs             同时启动 Vite 与本地服务
data/leaderboard.json       本地排行榜数据
data/settings.json          本地设置数据
```
