# 扫雷

一个使用 Vite、React、TypeScript 和本地 Node 服务实现的扫雷游戏。排行榜会保存到项目目录中的本地 JSON 文件。

## 功能

- 三档难度：简单、正常、困难。
- 首次有效左键后布雷，保证首点安全。
- 左键翻格、右键红色旗帜标记、空白区域自动展开。
- 胜负判定、计时和重新开始。
- 通关公告、加入排行榜和本地排行榜查询。
- 排行榜按用时从短到长排序，每页最多显示 10 条记录。

## 环境要求

- Node.js 18 或更高版本
- npm

## 安装

在项目根目录执行：

```bash
npm install
```

## 开发模式

执行：

```bash
npm run dev
```

该命令会同时启动：

- Vite 开发服务器：通常为 `http://127.0.0.1:5173/`
- 本地排行榜服务：`http://127.0.0.1:3001/`

在浏览器打开终端显示的 Vite 地址即可进入游戏。排行榜 API 会自动代理到本地服务，因此开发时不需要额外启动第二个终端。

使用 `Ctrl+C` 可以同时停止两个服务。

## 生产运行

先构建前端：

```bash
npm run build
```

再启动本地服务：

```bash
npm run start
```

浏览器访问：

```text
http://127.0.0.1:3001/
```

`npm run start` 会提供构建后的页面及排行榜 API。

## 游戏操作

- **难度菜单**：选择简单、正常或困难。切换后会立刻重置当前棋盘。
- **左键**：翻开格子。
- **右键**：为未翻开的格子添加或取消红色旗帜。
- **重新开始**：重置当前难度下的棋盘和计时。
- **查看排行榜**：查看本地通关记录；可使用上一页、下一页浏览更多记录。

## 难度

| 难度 | 棋盘 | 地雷数 |
| --- | --- | --- |
| 简单 | 9 x 9 | 10 |
| 正常 | 10 x 10 | 20 |
| 困难 | 12 x 12 | 30 |

## 排行榜存储

排行榜存放在项目根目录的 `data/leaderboard.json`。

每次在通关公告中点击“加入排行榜”时，服务会保存：

- 本局用时
- 所选难度
- 使用 UTC+8 格式记录的完成时间

记录按总用时从短到长排序。删除 `data/leaderboard.json` 中的内容即可清空本地排行榜；服务会在下一次保存时自动重新创建有效数据。

## 项目结构

```text
src/
  components/               状态栏、棋盘、格子和弹窗组件
  game/                     扫雷规则、难度与排行榜 API 客户端
  App.tsx                   游戏状态与交互连接
  styles.css                全局样式
server.mjs                  本地排行榜 API 与生产静态文件服务
scripts/dev.mjs             同时启动 Vite 与本地服务
data/leaderboard.json       本地排行榜数据
```
