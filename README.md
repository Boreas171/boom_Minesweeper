# 扫雷

一个基于 Vite、React 和 TypeScript 实现的小体量扫雷游戏。当前版本采用固定难度：`9 x 9` 棋盘，共 `10` 枚地雷。

## 快速开始

### 环境要求

- Node.js 18 或更高版本
- npm

### 安装依赖

在项目根目录执行：

```bash
npm install
```

### 启动游戏

启动 Vite 开发服务器：

```bash
npm run dev
```

命令执行后，终端会显示本地访问地址，例如：

```text
http://127.0.0.1:5173/
```

在浏览器中打开这个地址即可进入游戏。项目没有登录流程或额外配置，页面打开后就是扫雷棋盘。

如果需要明确指定本机地址，可以执行：

```bash
npm run dev -- --host 127.0.0.1
```

### 构建生产版本

检查 TypeScript 并生成生产文件：

```bash
npm run build
```

构建结果会输出到 `dist/` 目录。也可以使用 Vite 预览构建结果：

```bash
npm run preview
```

## 游戏操作

- **左键**：翻开格子。
- **右键**：为未翻开的格子插旗，重复右键可以取消旗帜。
- **重新开始**：点击顶部的“重新开始”按钮，清空当前棋盘并开始新的一局。

游戏规则：

- 地雷在第一次有效左键点击后生成，保证第一次点击的格子不是地雷。
- 翻开空白格时，会自动展开相邻的空白区域和数字格。
- 数字表示周围八个格子中的地雷数量。
- 翻开地雷后游戏失败，并展示所有地雷。
- 所有非雷格子都翻开后游戏胜利。
- 计时从第一次有效左键点击开始，胜利或失败后停止。

## 项目结构

```text
src/
  main.tsx                 React 入口
  App.tsx                  游戏状态管理与交互连接
  styles.css               全局样式
  game/
    types.ts               游戏数据类型
    constants.ts           默认难度和邻居方向
    board.ts               创建棋盘、布雷、计算相邻雷数
    reveal.ts              翻开、扩散、插旗和展示地雷
    victory.ts             旗帜统计、剩余雷数和胜利判断
  components/
    GameHeader.tsx         状态栏和重新开始按钮
    Board.tsx               棋盘网格
    Cell.tsx                单个格子
```

## 当前版本范围

当前版本只实现基础单人玩法，暂不包含自定义棋盘、难度选择、音效、主题切换、存档或排行榜等功能。
